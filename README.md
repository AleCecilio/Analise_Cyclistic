"# Analise_Cyclistic" 

## Fontes de Dados

Os dados utilizados neste projeto são provenientes do conjunto **Divvy Trip Data**, disponibilizado publicamente pela Divvy, sistema de compartilhamento de bicicletas de Chicago, Illinois, EUA.

Para a análise, serão utilizados os dados referentes aos **12 meses mais recentes disponíveis**, disponibilizados em arquivos mensais no formato CSV, compactados em arquivos ZIP.

Período analisado: setembro de 2025 a agosto de 2026

Os dados contêm informações sobre as viagens realizadas pelos usuários do sistema, incluindo:

* Identificador da viagem;
* Tipo de bicicleta utilizada;
* Data e horário de início da viagem;
* Data e horário de término da viagem;
* Estação de início;
* Estação de término;
* Identificadores das estações;
* Localização geográfica das estações;
* Tipo de usuário.

Os arquivos originais serão mantidos na pasta `data/raw/`. Posteriormente, os arquivos serão carregados, combinados e tratados utilizando **Python e Pandas**, dando origem aos dados processados utilizados na análise.

### Fonte

**Divvy — Bike Share Trip Data**

Os dados são disponibilizados publicamente pela Divvy e utilizados neste projeto para fins de análise de dados e aprendizado.

**Link dos Dados:** *https://divvy-tripdata.s3.amazonaws.com/index.html*
